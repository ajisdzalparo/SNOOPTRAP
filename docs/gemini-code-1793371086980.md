## Overview
Desain UI SnoopTrap dirancang khusus untuk menciptakan efek kejut dan intimidasi (The Trap) saat penyusup menyentuh laptop[cite: 2]. Tema "Cyber Security / Hacker" digunakan untuk memberikan kesan bahwa sistem sedang melakukan pelacakan balik dan mengambil alih kontrol secara absolut.

## Colors
Warna didominasi oleh `Pitch Black` dan merah peringatan (`#FF003C`) untuk menciptakan urgensi. Hijau terminal (`#00FF41`) digunakan secara spesifik hanya untuk elemen "log sistem" guna meniru antarmuka terminal peretas sungguhan.

## Typography
Seluruh tipografi diwajibkan menggunakan *font monospace* (seperti JetBrains Mono atau Fira Code). Tidak ada toleransi untuk *font sans-serif* biasa. Ini memastikan form OTP, *log* sistem, dan teks peringatan terlihat seperti *command line interface* (CLI).

## Spacing & Layout
Menggunakan *grid* padat untuk elemen HUD/Log di sudut-sudut layar untuk memberi kesan kompleksitas teknis, namun memberikan *whitespace* yang luas di tengah layar agar mata penyusup langsung tertuju pada peringatan merah dan form OTP.

## Shapes & Elevation
Absolut tajam. Tidak ada sudut membulat (*border-radius: 0*). Kedalaman (*depth*) tidak diciptakan melalui bayangan jatuh (*drop shadow*) standar, melainkan melalui pendaran neon (*glow/box-shadow*) dari elemen-elemen berwarna merah dan efek *backdrop-blur(20px)* yang menyensor desktop Windows di belakangnya[cite: 2].

## Rules to Never Break
- Jangan pernah menggunakan *border-radius* di atas 0px.
- Jangan gunakan warna putih sebagai latar belakang *surface*.
- Harus selalu mempertahankan *backdrop-blur* untuk memberikan konteks bahwa aplikasi asli milik pengguna sedang "disandera" di belakang layar pelindung[cite: 2].
